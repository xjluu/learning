## Course Link

[FREE Summer of CCNA - NetworkChuck Academy](https://academy.networkchuck.com/course/free-summer-of-ccna)

## Course Overview

The **FREE Summer of CCNA** is a guided CCNA study program from NetworkChuck Academy. The program is designed to help learners stay consistent, accountable, and focused while preparing for the Cisco CCNA exam.

The course includes a structured roadmap, video lessons, ebook content, practice questions, live sessions, and study milestones.

## Course Goal

My goal for this course is to strengthen my networking foundation and prepare for the CCNA by practicing the following skills:

- Network fundamentals
- IP addressing and subnetting
- Switching concepts
- VLANs and trunking
- Routing concepts
- Static routing
- OSPF
- NAT
- DHCP
- ACLs
- Wireless networking basics
- Network security basics
- Cisco IOS command-line practice
- Packet Tracer lab practice
